# 实验负载族与对照族

装置的测量按族组织，当前有两族：负载族回答用什么负载测，对照族把 KVFerry 与对照组放在同一格上比较。两族共用同一批轨迹文件与同一套命令入口。

## 族与格

族是负载维度的组合模板，格是族中取定一组值的单个组合，轨迹是一份请求剧本。三个词不混用：格跑一轮用一份轨迹。KV 池容量与副本数不进族，全族取同一个值（R3）。冷热是每格的两种跑法（R4）。

格 ID 编码该格的三个维度：`p<前缀比例>-len<长度档>-<压力档>`，前缀比例取 p0、p50、p80，长度档取 lenshort、lenmid、lenlong，压力档取 low、high。例如 p80-lenlong-high 是前缀 80%、长档、高压力的格。

## 负载族

负载族由三个维度构成：共享前缀比例三档（D6）、输入长度三档（D5）、压力两档（D7），组合成十八格：

| 格 ID             | 前缀档 | 长度档 | 压力档 |
|-------------------|--------|--------|--------|
| p0-lenshort-low   | 0%     | 短     | 低     |
| p0-lenshort-high  | 0%     | 短     | 高     |
| p0-lenmid-low     | 0%     | 中     | 低     |
| p0-lenmid-high    | 0%     | 中     | 高     |
| p0-lenlong-low    | 0%     | 长     | 低     |
| p0-lenlong-high   | 0%     | 长     | 高     |
| p50-lenshort-low  | 50%    | 短     | 低     |
| p50-lenshort-high | 50%    | 短     | 高     |
| p50-lenmid-low    | 50%    | 中     | 低     |
| p50-lenmid-high   | 50%    | 中     | 高     |
| p50-lenlong-low   | 50%    | 长     | 低     |
| p50-lenlong-high  | 50%    | 长     | 高     |
| p80-lenshort-low  | 80%    | 短     | 低     |
| p80-lenshort-high | 80%    | 短     | 高     |
| p80-lenmid-low    | 80%    | 中     | 低     |
| p80-lenmid-high   | 80%    | 中     | 高     |
| p80-lenlong-low   | 80%    | 长     | 低     |
| p80-lenlong-high  | 80%    | 长     | 高     |

每格用冷、热两种跑法各跑 `--reps` 轮，缺省 2，同跑法的两轮做复跑对账（D10）。负载族原生基线首轮共 72 轮，全部跑完再考虑砍格（R4）。每格的轨迹文件由轨迹生成器按 D1、D2、D4 构造，格式与字段按 D1、D2 执行。

压力两档按 D7 的队列积压判定条件划分。到达率按基线完成速率的倍数缩放：低压力档取 `LOW_LOAD_SCALE`，高压力档取 `HIGH_LOAD_SCALE`，倍数是首轮校准的初始值（4.1 参数总表）；基线完成速率由装置在 native 组跑一轮中等长度轨迹测出。

## 对照族

对照族共六组，组 ID、存储挂载与决策配置按 D14、D15 执行：

| 组 ID         | 存储挂载               | 路由   | 取回与重算决策   |
|---------------|------------------------|--------|------------------|
| native        | 无，只有本地前缀缓存   | sticky | 无 offload       |
| fetch-all     | KVFerry 存储           | sticky | 旁路开关强制取回 |
| recompute-all | KVFerry 存储，写入照常 | sticky | 旁路开关强制重算 |
| sticky-static | 分层存储常开           | sticky | 静态配置         |
| connector     | vLLM 自带 CPU offload  | sticky | 静态字节预算     |
| kvferry       | KVFerry 存储           | sticky | 在线查表决策     |

sticky 指同一会话的请求固定路由到同一个副本，前缀缓存因此只在副本内积累与命中。六组的路由全部取 sticky，路由策略不进对照变量，六组之间只比存储与决策的差异。六组读同一份轨迹，KV 池容量与副本数取同值（R3）。

决策配置由 fetch-policy 与预算键承载（D14）：fetch-all 取 force-fetch，recompute-all 取 force-recompute，sticky-static 取 static 加 fetch-budget，connector 用 vLLM OffloadingConnector 加 connector-budget，kvferry 取 online。组配置属于组参数，由 up 写进组件启动参数，不写进轨迹文件。

对照族的规模是六组乘 18 格乘冷热两跑法乘每跑法轮数（缺省 2），共 432 轮，与负载族共用同一批轨迹。负载族原生基线先跑：基线完成速率是压力档倍数的输入，也是六组对照里的 native 组参照。
