# 陷阱清单

集中登记操作与流程层的陷阱，按模块分节。收录规则：

1. 只收会再踩的：换个人做、换个格跑、换个模块改还会踩到才收，一次性的调试过程不收。
2. 只收有代价的：后果是数字作废、结果无法解释或重跑才收，一眼能看出的报错不收。
3. 设计取舍层面的内容写在正式文档正文对应小节，本清单不重复登记。

## 实验装置

| 陷阱                                          | 后果                                                   | 预防                                                     |
|-----------------------------------------------|--------------------------------------------------------|----------------------------------------------------------|
| 负载台的 CPU 或连接数先于引擎饱和             | 测出的是负载台上限，不是引擎上限，数字不可用           | 每轮记录负载台资源水位，饱和轮次作废                     |
| 冷热两态混在同一份结果里                      | 命中率数字无法解释                                     | 冷热分表记录，分开报                                     |
| 不同模型档位的数字混着比                      | 口径不一致，对照不成立                                 | S/M/L 各档分开报，跨档位只比结论方向不比绝对值           |
| up 拉起的副本注册名与负载台请求的模型名不一致 | 每个请求被副本拒绝，轮内无 TTFT，整轮作废              | up 后核对副本 /v1/models 注册名（4.4「拉起」节）         |
| 批量清理与启动用同一模式串 pkill/启动         | 模式匹配到自身命令行，杀掉执行中的 shell，新任务未启动 | 清理与启动分开执行，模式串用 `[x]` 字符类避免自匹配      |
| 会话内启动的长任务随工具调用中断被连带终止    | 跑到一半的轮被杀，留半截轮目录                         | 长任务用 setsid 独立进程组脱离会话，启动后确认进程组存活 |
## 最小块存储

| 陷阱                                        | 后果                                                           | 预防                                              |
|---------------------------------------------|----------------------------------------------------------------|---------------------------------------------------|
| gRPC 单条消息上限保持默认 4 MiB             | 8 MiB 块的写入与读回消息被框架拒收，灌块验证全挂               | 服务端与客户端两侧同步把单条消息上限配到 10 MB    |
| KV 口径声明与引擎实际口径不一致             | 跨口径块进入命中集，读回字节与引擎期望不符，命中作废转重算     | 口径随挂载声明并与引擎配置同源，读回长度校验必开  |
| 存储侧自行实现哈希链算键                    | 算出的键与引擎产出的块哈希对不上，全量判未命中或错误命中       | 键直接消费引擎 connector 产出，键口径变更跟随引擎 |
| 事件先于数据 fsync 发射                     | 断电后索引登记盘上不存在的块，读回只能拿 DataLoss              | 段层 Put 固定顺序：CRC 写全并 fsync 返回后才发 register |
| 位图或快照先于段头作为对账权威              | 快照残留位图把空段当占用或漏标已写段，容量泄漏或重复登记       | 启动对账一律以段头状态为唯一权威修正位图          |
| 驱逐先回位图再摘键                          | 新键立刻复用该段，索引在事件到达前仍按旧登记命中，读回键不符   | 驱逐顺序固定：先摘键，等在途读归零，发事件后才回位图 |
| 口径变更只重写文件头不清段区                | 旧口径段头被启动对账当有效段保留，跨口径块混入命中集           | 口径不一致时按文件粒度删除数据大文件整盘重建      |
| 重建窗口按部分节点收齐提前放行              | 未重报节点的登记缺失或过期，错误命中比重算更贵                 | 命中查询在窗口关闭前一律未命中，全部节点收齐才关窗 |
