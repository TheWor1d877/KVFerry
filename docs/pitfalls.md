# 陷阱清单

集中登记操作与流程层的陷阱，按模块分节。收录规则：

1. 只收会再踩的：换个人做、换个格跑、换个模块改还会踩到才收，一次性的调试过程不收。
2. 只收有代价的：后果是数字作废、结果无法解释或重跑才收，一眼能看出的报错不收。
3. 设计取舍层面的内容写在正式文档正文对应小节，本清单不重复登记。

## 实验装置

| 陷阱 | 后果 | 预防 |
|---|---|---|
| 负载台的 CPU 或连接数先于引擎饱和 | 测出的是负载台上限，不是引擎上限，数字不可用 | 每轮记录负载台资源水位，饱和轮次作废 |
| 冷热两态混在同一份结果里 | 命中率数字无法解释 | 冷热分表记录，分开报 |
| 不同模型档位的数字混着比 | 口径不一致，对照不成立 | S/M/L 各档分开报，跨档位只比结论方向不比绝对值 |
