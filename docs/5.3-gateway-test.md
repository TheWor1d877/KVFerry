# 网关测试

## 测试文件表

| 文件 | 测什么 | 覆盖场景 |
|---|---|---|
| internal/config/config_test.go | 配置加载与覆盖 | 缺省值、flag 覆盖单项、缺 upstreams 报错（D16） |
| internal/proxy/session_test.go | 会话标识解析 | 三种来源：`X-Session-ID`、`X-KVFerry-Session` 与请求体（D17）、body 解析失败返回 error、三处全缺返回空 |
| internal/proxy/proxy_test.go | 转发与透传 | 请求头与体原样到达模拟上游（D18）、响应透传、独立请求不进映射、同会话落同副本与摘除后改粘（D19） |
| internal/proxy/reroute_test.go | 改路 | 响应头前失败改路一次、流式开始后断流不改路、无 `X-Request-Id` 的改路事件字段为空（D18、D20） |
| internal/proxy/error_test.go | 错误响应 | 全摘 503 带判据头与响应体、上游错误原样透传不改写（D24） |
| internal/probe/probe_test.go | 探针摘除与恢复 | 连续失败摘除、连续成功恢复、超时计失败、检测延迟口径（D21） |
| internal/drill/buffer_test.go | 事件缓冲 | remove、recover、reroute 三类事件字段（D22）、拉取即清空、1024 溢出丢最旧 |
| internal/drill/http_test.go | 事件接口 | GET 返回 JSON 数组并清空、非 GET 回 405（D22） |
| internal/sticky/table_test.go | 会话映射并发 | 并发 Assign 与 DropNode 不丢条目、重启即空（D19） |
| internal/health/health_test.go | 网关健康端点 | `/health` 返回 200（D23） |

模拟上游用 httptest.Server 构造，可注入拒绝连接、挂起超时、慢响应三类故障，不依赖真实引擎。
