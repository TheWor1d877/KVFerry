# 实验装置指标

负载台按下列指标采集每轮结果，轮次有效性判断与决策记录的评估都以这些定义为准。指标值由负载台在轮内采集，决策类指标由决策服务写入的字段算出。

## TTFT

TTFT 是负载台发出请求到收到该请求首个输出 token 的时长，单位毫秒。负载台在发出请求时记 t_send，收到首个输出 token 时记 t_first，TTFT 等于两者之差。每轮报 P50 与 P90，按格、按组、按冷热分开报。探针摘除副本后改路的请求，TTFT 覆盖改路等待与重算的总时长，改路事件记进演练记录，解读 TTFT 分布时结合该记录判断长尾来自改路还是来自排队。

## 前缀命中率

前缀命中率是命中前缀 token 数占输入 token 数的比例。负载台从引擎响应的 prompt_tokens_details.cached_tokens 读命中 token 数，除以该请求的 n_input。每请求一个值，每轮汇总报均值与分布。合成段计入可共享前缀，归因依据是轨迹元数据的 synthetic_ratio（D4）：报告同时列出该格的目标比例与实测命中率，两者之差反映真实 trace 段的复用水平。改路后的请求在新副本上丢失前缀缓存，这类请求的命中率下降如实计入，解读时对照演练记录的改路事件。

## 取回字节

取回字节是从分层存储取回的 KV 字节数，量级上等于取回 token 数乘该档 KV 每 token 字节数（4.0 口径纪律）。负载台每轮从存储层的取回计数读累计值，写进该轮 run_meta.json。口径随代价表版本切换，报告按对应口径标注。取回字节只在挂分层存储的组上采集（D15）；native 与 connector 组的复用发生在引擎或连接器内部，不计入该指标。

## 决策偏差

决策偏差衡量决策记录里估计耗时的可靠性，单位毫秒。对取回动作，偏差等于（实际取回完成时刻减触发时点）减估计取回耗时；对重算动作，偏差等于实际重算耗时减估计重算耗时。偏差为正表示实际耗时超过估计，持续为正的档位说明代价表的该行需要重标定。按动作分组报分布，再按格与模型档汇总，字段来自 D9。

## 置信档交叉表

置信档与实际动作的计数交叉表，行是置信档，列是取回、重算、不可取回。交叉表按格汇总后随 collect 进 summary.csv。置信档的档位集合由决策服务定义，装置只按写入值分列，字段来自 D9。

## 对账量

对账量是完成请求数、输入 token 总数、输出 token 总数三个量。完成请求数按收到末个 token 的请求计；输出 token 总数取引擎上报的 completion_tokens，缺该字段时按响应流的输出块计数；输入 token 总数按轨迹元数据的 n_requests 与各请求 n_input 之和核验。负载台每轮累计，复跑判定（D10）比较同格两轮的三个量：请求数与 token 数必须精确相等，P50 TTFT 偏差不超过 10%。

## 轮次有效性判定

每轮跑完后，负载台按三步判定该轮是否有效，任何一步不通过整轮作废：

1. 对账：与同格上一轮比较对账量（D10）。
2. 饱和：检查每秒采样的负载台 CPU 占用与连接数，负载台先于引擎饱和的轮作废（D11）。
3. 压力档：在 `MEASURE_WINDOW_S` 窗口内按 D7 计算队列非空状态，与该格压力档比对。

作废轮移进该轮目录的 quarantine/ 子目录，原因写进 run_meta.json。压力档验证不达标是格构造偏差，不是轮次作废：轨迹生成器调整到达间隔倍数重新生成轨迹，重跑该格。

## 报数纪律

模型档位之间分开报，跨档位只比结论方向，不比绝对值。冷热两态的数字分开报。取回字节与取回耗时的口径随代价表版本切换，报告标注版本。作废轮的全部数字不进汇总，summary.csv 只收有效轮（D13）。

## 决策记录

决策记录按 D9 的字段全集写入 decision.jsonl，逐出与升温事件按 D8 写进各自的事件表。决策记录支撑两项评估：决策偏差的分布，置信档交叉表，随决策服务接入后由 collect 产出；装置阶段 decision.jsonl 是空表。
