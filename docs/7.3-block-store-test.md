## 覆盖缺口

| 缺什么                       | 优先级 | 怎么补                                                             |
|------------------------------|--------|--------------------------------------------------------------------|
| 真实多机存储节点与跨机网络   | 高     | 两台以上存储机接真实网络跑跨机读回与失联判定                       |
| RDMA 与 GPUDirect Storage 直通显存 | 中 | 换支持 RDMA 的机器与驱动，按传输路径实测                          |
| 零拷贝 fd 与注册内存字段     | 中     | 传输引擎接口落地后接真实注册内存                                   |
| 真实 NVMe 介质故障与坏块     | 中     | 注入块设备错误或用故障盘演练                                       |
| k8s DaemonSet 滚动升级       | 中     | 集群内升级一次副本并观察读请求中断                                 |
| 决策服务真实进程重启的端到端时延 | 低 | 双进程压测重启窗口                                                 |
| 大容量段文件与位图规模       | 低     | 按单节点容量上限灌满后测启动扫描耗时                               |
