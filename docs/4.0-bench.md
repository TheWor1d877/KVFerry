# 实验装置

实验装置给 KVFerry 的对照测量提供可复现的负载、统一的请求入口与完整的记录。装置与正式项目代码分离，删除装置目录后正式项目不受影响。

## 装置组成

装置由负载台、网关、引擎副本与实验记录表四部分组成。负载台按轨迹文件放请求，统计每轮的完成请求数与延迟分布。被测对象是原生引擎副本，只带本地前缀缓存；取回组件挂载后，装置组成与运行方式不变。

网关是正式项目的独立组件，装置复用它作为流量入口。网关接收负载台发出的请求，透传请求携带的会话编号与策略字段，按前缀亲和把请求路由到引擎副本；探针判定副本不健康时摘除该副本，在飞请求改路到其余副本重新计算，改路记一条事件。会话编号由负载台按会话携带，同一会话的请求共用一个编号，网关只透传不生成。

实验记录表是装置的输出账本，共四张，全部按 request id 或块哈希关联。决策记录由决策服务写入，装置阶段只定表结构与写入通路。

| 表             | 粒度       | 记什么                             |
|----------------|------------|------------------------------------|
| 决策记录       | 每请求一条 | 决策动作、命中信息、估计与实际耗时 |
| 退回与降级事件 | 每次一条   | 时刻、类型、原因                   |
| 驱逐事件       | 每块一条   | 块哈希、层位、原因                 |
| 演练记录       | 每次一条   | 时刻、节点编号、手段、命中率曲线   |

## 负载族

负载族回答用什么负载测。一个族是一组负载维度的组合模板，当前的族由三个维度构成：共享前缀比例三档、输入长度分布三档、压力两档，组合成十八格。每一格用冷、热两种跑法各跑一轮。KV 池容量与副本数不进族，全族取同一个值，这是各组对照的前提。当前的族是负载族，之后按测量需要扩充别的族。

轨迹文件是一份请求剧本，记录每个请求的到达时刻、输入长度与内容。分档参数写进轨迹文件名，换档换文件，不改代码。轨迹元数据随文件记录三件事：该格的共享前缀比例、压力档定义、合成段与真实段的占比。真实轨迹的共享前缀比例达不到该格要求时，合成一段公共前缀拼进请求头部补齐，合成占比写进元数据，防止命中率无法归因。

压力两档按定性判据划分：低负载指到达率低于单副本容量，高压力指到达率超过容量、请求队列持续积压。容量用原生基线的完成速率估算。

## 模型口径

模型按参数量分 S、M、L 三档，由装置参数指定，一套装置不改结构。三档取同一模型家族，结构口径一致，换档只换数值不换形态。档位与机器配置区间对应：每档的最低显存要求等于该档模型的权重占用与 KV 池容量之和，配置低于该值的机器不跑该档。

| 档位 | 模型        | 最低显存 |
|------|-------------|----------|
| S    | Qwen3-1.7B  | 7 GB     |
| M    | Qwen3-8B    | 32 GB    |
| L    | Qwen3-14B   | 37 GB    |

KV 每 token 字节数与块大小按实际模型计算，记进代价表口径。

## 口径纪律

- 模型档位之间分开报，跨档位只比结论方向，不比绝对值。
- 冷热两态的数字分开报。
- 传输路径口径随代价表版本切换，报告按对应口径标注。

## 运行纪律

- 一条命令拉起。单机进程级脚本拉起网关、引擎副本与负载台。
- 数据落仓库外的数据目录，仓库内只存脚本与清单。轨迹与每轮结果落数据目录，复现要素随结果入库。
- 冷态规程：每轮重启副本，清空 KV 池与存储层。
- 热态规程：先按该格的共享前缀比例打一轮预热请求，命中率与 step 时间回到稳态后开始计数，预热轮不计入结果。
- 复跑一致性：同一轨迹重跑两次，请求数与 token 数精确相等，P50 TTFT 偏差不超过 10%；超出判装置不稳，该轮作废。
- 负载台自检：每轮记录负载台的资源水位，负载台的 CPU 或连接数先于引擎饱和的轮次作废。

## 过关标准

- 一条命令拉起网关、引擎副本与负载台。
- 同一轨迹重跑两次，请求数与 token 数精确相等，P50 TTFT 偏差不超过 10%。
- 负载族十八格的轨迹各能生成，冷热两态各能跑通。
- 原生基线跑完全族十八格，结果入库。
