# 代价表测试

## 测试文件表

| 文件                          | 测什么               | 覆盖场景                                                                                                                             |
|-------------------------------|----------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| calibrate/test_config.py      | 配置键读取与口径采集 | 七个漂移键的缺省值与逐键覆盖（D32）、根目录缺失报错（D36）、版本变量未设置记 unknown（D30）、外部命令失败时口径字段记 unknown        |
| calibrate/test_tables.py      | 表落盘与加载校验     | 五份表文件与顶层字段（D26）、manifest 哈希与目录版本校验（D29）、声明版本不一致拒绝加载（D30）、撞名等待重试、失败路径临时目录不残留 |
| calibrate/test_fetchbench.py  | 线性拟合与三重检查   | 斜率倒数与截距、中位数与 p25 双拟合、最小档不进拟合、三重检查各项触发、加密挡位至多两轮（D31、D27）                                  |
| calibrate/test_recompbench.py | 每 token 时间口径    | 分母取实际 token 数、随机前缀零命中、64k 直测档同构存储、混批 1 路 decode（D27）                                                     |
| calibrate/test_interbench.py  | 表结构定值与扫描     | 正反子表行列与纯计算列（D28）、T4 两键、迟滞五档扫描选档、并发上限拐点（D31、R19）                                                   |
| calibrate/test_run.py         | 命令退出码与落盘     | 任一链路失败退出码 1 且不落目录、三重检查未过退出码 1、全部通过退出码 0 且五文件与 manifest 齐全（D31）                              |
| calibrate/test_probe.py       | 探针越阈计数与判定   | 越阈计数、不越阈清零、连续三窗判定过期、过期态跳过比对直接重试、成功后重载表（D33）                                                  |
| calibrate/test_passive.py     | 被动窗口聚合与判定   | 在飞块数非零样本丢弃、就近映射档位、开满下限且凑样聚合、到上限不足样本不产出不清零不推进、连续三窗触发重标（D34）                    |
| calibrate/test_recalib.py     | 局部重标与新版本落盘 | 成功落新版本且未重标文件原样复制（D29）、三重检查未过返回 False 不落盘、事件三连字段（R18、D35）                                     |
| calibrate/test_events.py      | 事件字段完整性       | 三类事件的公共字段与专有字段、phase 与 result 取值、一行一个 JSON 对象（D35）                                                        |

引擎与拷贝测量在单测里用假客户端与注入的测量函数替换，窗口时钟用注入时钟推进；真机测量由标定命令承担，单测覆盖拟合、聚合、计数、落盘与事件逻辑。

## 命令

```bash
# 仓库根执行；.venv 已建立（python3 -m venv .venv），pytest 与 calibrate 依赖已装入该环境
.venv/bin/python -m pytest calibrate/ -q
.venv/bin/python -m compileall -q calibrate/
```
